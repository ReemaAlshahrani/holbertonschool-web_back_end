# ES6 Classes

This project contains various exercises and tasks to learn and practice ES6 Classes, Metaprogramming, Getters, Setters, Inheritance, and Symbols in JavaScript.

## Files Description

| File Name | Description |
| :--- | :--- |
| `0-classroom.js` | Defines a `ClassRoom` class that accepts `maxStudentsSize`. |
| `1-make_classrooms.js` | Exports a function that returns an array of 3 `ClassRoom` objects with specific sizes. |
| `2-hbtn_course.js` | Implements a `HolbertonCourse` class with type-checked getters and setters. |
| `3-currency.js` | Implements a `Currency` class with code, name, and `displayFullCurrency` method. |
| `4-pricing.js` | Implements a `Pricing` class with amount, currency, `displayFullPrice`, and static `convertPrice`. |
| `5-building.js` | Implements an abstract `Building` class with `sqft` and a mandatory `evacuationWarningMessage` override. |
| `6-sky_high.js` | Implements a `SkyHighBuilding` class extending `Building` with floors and custom warning message. |
| `7-airport.js` | Implements an `Airport` class with a custom string description using `Symbol.toStringTag`. |
| `8-hbtn_class.js` | Implements a `HolbertonClass` supporting number and string casting via `Symbol.toPrimitive`. |
| `9-hoisting.js` | Fixes hoisting issues and exports `HolbertonClass`, `StudentHolberton`, and a list of students. |
| `10-car.js` | Implements a `Car` class with a `cloneCar` method using `Symbol.species`. |
