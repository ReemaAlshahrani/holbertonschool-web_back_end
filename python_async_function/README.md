# Python - Async

This project explores asynchronous programming in Python using asyncio, coroutines, tasks, and measuring execution performance.

| File Name | Description |
| :--- | :--- |
| `0-basic_async_syntax.py` | An asynchronous coroutine that waits for a random delay up to a given max and returns it. |
| `1-concurrent_coroutines.py` | Spawns multiple coroutines concurrently and returns their delays in ascending order. |
| `2-measure_runtime.py` | Measures the total execution time for concurrent tasks and calculates the average time per task. |
| `3-tasks.py` | Creates an `asyncio.Task` object from an asynchronous coroutine. |
| `4-tasks.py` | Uses `task_wait_random` to spawn multiple tasks concurrently and return their sorted delays. |
