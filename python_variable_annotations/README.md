# Python - Variable Annotations

This directory contains Python scripts demonstrating the use of variable type annotations, type checking with mypy, and code style validation with pycodestyle.

| File Name | Description |
| --- | --- |
| `0-add.py` | Function that adds two floats and returns their sum with type annotations. |
| `1-concat.py` | Function that concatenates two strings and returns the result. |
| `2-floor.py` | Function that returns the floor of a float number. |
| `3-to_str.py` | Function that converts a float to its string representation. |
| `4-define_variables.py` | Defines and annotates variables with specific types. |
| `5-sum_list.py` | Function that takes a list of floats and returns their sum. |
| `6-sum_mixed_list.py` | Function that takes a list of integers and floats and returns their sum. |
| `7-to_kv.py` | Function that returns a tuple with a string and the square of an int/float. |
| `8-make_multiplier.py` | Function that returns a multiplier function. |
| `9-element_length.py` | Function that returns the length of elements in an iterable. |
| `100-safe_first_element.py` | Function that safely retrieves the first element of a sequence. |
| `101-safely_get_value.py` | Generic function to retrieve values from a mapping safely. |
| `102-type_checking.py` | Function that zooms in on a tuple with type checking validation using mypy. |my project
