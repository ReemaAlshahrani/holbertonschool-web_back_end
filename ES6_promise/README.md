# ES6 Promises

This project contains exercises and tasks to learn and practice asynchronous programming in JavaScript using ES6 Promises, `async`/`await`, and error handling (`try`/`catch`).

## File Descriptions

| File Name | Description |
| :--- | :--- |
| `0-promise.js` | Returns a standard Promise object. |
| `1-promise.js` | Returns a promise that resolves or rejects based on a boolean parameter. |
| `2-then.js` | Appends `.then()`, `.catch()`, and `.finally()` handlers to a promise. |
| `3-all.js` | Uses `Promise.all` to collectively resolve multiple profile signup promises. |
| `4-user-promise.js` | Returns a resolved promise containing user first and last names. |
| `5-photo-reject.js` | Returns a rejected promise with a custom error message for photo processing. |
| `6-final-user.js` | Uses `Promise.allSettled` to handle multiple settled promises and return their statuses. |
| `7-load_balancer.js` | Uses `Promise.race` to return the value of the fastest resolving promise. |
| `8-try.js` | Performs division and throws an error if the denominator is zero. |
| `9-try.js` | Implements a guardrail function using `try/catch/finally` to log results and errors into a queue. |
