# ES6 Basics

This project covers the fundamentals of ECMAScript 6 (ES6), introducing modern JavaScript features, configuration tools, and best practices.

## Project Files

| File Name | Description |
| --------- | ----------- |
| `package.json` | Contains project metadata, dependencies (Babel, Jest, ESLint), and execution scripts. |
| `babel.config.js` | Configuration file for Babel to transpile modern JavaScript code. |
| `.eslintrc.js` | Configuration file for ESLint code linter and style rules. |
| `0-constants.js` | Demonstrates the usage of `const` and `let` variable declarations. |
| `1-block-scoped.js` | Explores block-scoping behavior and variable protection. |
| `2-arrow.js` | Introduces ES6 arrow functions and `this` binding context. |
| `3-default-parameter.js` | Demonstrates the usage of default function parameters. |
| `4-rest-parameter.js` | Explores the rest parameter `...` to handle a variable number of arguments. |
| `5-spread-operator.js` | Demonstrates concatenating arrays using the spread operator. |
| `6-string-interpolation.js` | Explores template literals for string interpolation. |
| `7-getBudgetObject.js` | Uses object property shorthand for concise object creation. |
| `8-getBudgetCurrentYear.js` | Demonstrates ES6 computed property names in objects. |
| `9-getFullBudget.js` | Implements ES6 method properties within objects. |
| `10-loops.js` | Demonstrates iterating through arrays using the modern `for...of` loop. |
| `11-createEmployeesObject.js` | Creates employee objects using computed property names. |
| `12-createReportObject.js` | Generates a comprehensive report object using spread syntax and method properties. |
| `100-createIteratorObject.js` | Implements custom iterators to traverse through department employees. |
| `101-iterateThroughObject.js` | Consumes an iterator object to format a string list of employee names. |

## Requirements
- Ubuntu 20.04 LTS
- Node.js (version 20.x.x)
- npm (version 9.x.x)
- Testing Framework: Jest
- Linter: ESLint
