# ES6 Data Manipulation

This project contains various exercises and tasks to practice advanced data manipulation in JavaScript (ES6), including arrays, typed arrays, sets, maps, and weak maps.

## Tasks Overview

| Task | File Name | Description |
| :--- | :--- | :--- |
| **0. Basic list of objects** | `0-get_list_students.js` | Returns an array of student objects containing `id`, `firstName`, and `location`. |
| **1. More mapping** | `1-get_list_student_ids.js` | Uses `map` to extract an array of student IDs from a list of student objects. |
| **2. Filter** | `2-get_students_by_loc.js` | Uses `filter` to return an array of students located in a specific city. |
| **3. Reduce** | `3-get_ids_sum.js` | Uses `reduce` to calculate and return the sum of all student IDs. |
| **4. Combine** | `4-update_grade_by_city.js` | Combines `filter` and `map` to update student grades for a specific city. |
| **5. Typed Arrays** | `5-typed_arrays.js` | Creates a new `ArrayBuffer` with an `Int8` value at a specific position using `DataView`. |
| **6. Set data structure** | `6-set.js` | Creates and returns a `Set` data structure from an array. |
| **7. More set data structure** | `7-has_array_values.js` | Checks if all elements of an array exist within a given `Set` (returns a boolean). |
| **8. Clean set** | `8-clean_set.js` | Returns a hyphen-separated string of set values that start with a specific prefix. |
| **9. Map data structure** | `9-groceries_list.js` | Returns a `Map` data structure containing a list of grocery items and their quantities. |
| **10. More map data structure** | `10-update_uniq_items.js` | Updates items in a grocery map where the initial quantity is `1` to `100`. |
